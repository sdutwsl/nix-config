# 全局操作限制

- 未经用户针对具体操作的明确允许，禁止修改系统设置。
- 系统设置包括但不限于：防火墙规则、端口放行、网络接口与路由、DNS、代理、内核参数、系统服务、NixOS 或其他系统配置、系统级软件包、权限与安全策略，以及手机的系统设置。
- 用户要求实现、调试、测试或运行应用，不代表允许修改系统设置。具有 sudo/root 权限、操作可撤销或仅临时生效，都不能代替用户的明确授权。
- 遇到系统设置阻碍任务时，只能先做只读诊断，并说明必要的系统改动；得到用户明确允许后才能执行对应改动。
- 未经明确允许，也禁止以自动修复、验证、清理或回滚为由，添加、修改或删除已有系统设置。授权仅适用于用户明确同意的操作与范围。
